GOOD TO KNOW

A few things you might be wondering.

Will I pay a monthly hosting fee?+

Hosting is included for the brochure site packages, with no monthly website hosting charge. You’ll still need to pay for your domain registration and any third-party services you choose.

Can I use my existing domain?+

Yes. We can connect a domain you already own when the site is ready to launch.

Can I update the website later?+

Yes. The site files are yours, so you can edit them yourself if you know HTML and CSS. Or choose our £25 + VAT per month update plan, which includes up to two content updates each month. Larger changes can be quoted separately.

Do you build online shops?+

These packages cover brochure websites. We can discuss updates to an existing Shopify store as a separate project.
